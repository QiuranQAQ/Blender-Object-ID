# **Blender物体ID插件 v0.1**

使用了Blender原生的视图物体颜色属性

可以自定义物体通道颜色

可以统一设置该集合下所有物体ID颜色

可以将物体加入ID通道（关联复制不影响原始集合），实现跨集合赋予物体颜色属性

可一键隐藏创建的ID集合

已知4.2.3LTS  4.3.2正常运行

看到一些群友有这方面需求，但Blender手动操作起来麻烦又困难，所以结合Deepseek写了这个插件，开发耗时2小时

## **请提前设置Blender渲染模式**

*渲染引擎：工作台*

*采样：32次采样*

*光照：平面*

*颜色：属性*

## **额外说明**

*基于Blender关联复制的特性，你可以用灯光链接设置灯光id通道，避免把原始工程拆的支离破碎*

*设置集合颜色会覆盖物体颜色，注意使用顺序*

*给15个通道感觉够用了，除非你是真的饿了O_O*

*要是有什么bug就再说吧，够用就行了*
